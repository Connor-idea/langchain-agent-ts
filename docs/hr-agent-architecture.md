# HR Agent 架构设计

## 核心理念

HR 的工作不是单点任务，是**选育用留**的持续循环。每个环节的输出是下一个环节的输入。

## 全链路地图

```
┌─────────────────────────────────────────────────────────────────────┐
│                        选 育 用 留 循环                              │
└─────────────────────────────────────────────────────────────────────┘

  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │   选      │───→│   育      │───→│   用      │───→│   留      │
  │  Select   │    │  Train   │    │  Use     │    │  Retain  │
  └──────────┘    └──────────┘    └──────────┘    └──────────┘
       │               │               │               │
       ↕               ↕               ↕               ↕
  招进来            培养好           用对了           留得住
```

## 选（Select）— 招聘漏斗

```
部门需求 ──→ JD 生成 ──→ 渠道发布 ──→ 简历筛选 ──→ 面试安排 ──→ 评估决策 ──→ Offer
   │            │           │           │           │           │          │
   │     三角色审查     多平台同步    匹配度打分    问题定制     多维评估    薪酬建议
   │     PM/技术/HRD   BOSS/猎聘     硬性+软性     岗位定制     能力模型    市场对标
   │
   └─→ 上游：业务部门的战略目标、团队现状、预算
```

### 选 各节点详情

| 节点 | 输入 | 输出 | 下游 | Agent 能力 |
|------|------|------|------|-----------|
| **部门需求** | 业务目标、团队缺口、预算 | 需求文档 | → JD 生成 | 需求访谈引导 |
| **JD 生成** | 需求文档 + 行业基准 | 结构化 JD | → 渠道发布、面试问题 | 三角色自批评 |
| **渠道发布** | JD + 目标平台 | 多平台发布状态 | → 简历收集 | 多平台 API |
| **简历筛选** | 简历 + JD | 匹配度评分 + 筛选理由 | → 面试安排 | 硬性/软性匹配 |
| **面试安排** | 候选人 + JD + 面试官 | 面试计划 | → 面试执行 | 时间协调 |
| **面试问题** | JD + 候选人简历 + 岗位模型 | 定制化问题列表 | → 面试评估 | 多类型问题生成 |
| **面试评估** | 面试记录 + 评分标准 | 评估报告 | → 录用决策 | 多维评分 |
| **Offer** | 评估结果 + 薪酬带 | Offer 建议 | → 入职（育） | 市场对标 |

## 育（Train）— 成长路径

```
入职 ──→ 培训计划 ──→ 试用期跟踪 ──→ 能力评估 ──→ 转正决策
  │          │            │             │           │
  入职引导    岗位定制      阶段反馈      能力模型      综合评估
  文化融入    技能缺口      目标达成率    成长曲线      发展建议
```

## 用（Use）— 持续赋能

```
目标设定 ──→ 绩效跟踪 ──→ 反馈辅导 ──→ 岗位调整 ──→ 晋升评估
   │           │           │           │           │
   OKR/KPI     定期回顾     1:1 管理     人岗匹配     能力画像
   对齐公司目标  数据驱动     发展导向     内部流动      继任规划
```

## 留（Retain）— 长期绑定

```
满意度调查 ──→ 风险预警 ──→ 留人干预 ──→ 离职分析 ──→ 改进闭环
    │            │           │           │           │
    定期脉搏      离职预测     谈话建议     离职原因     流程改进
    行业对标      信号识别     方案定制     数据沉淀     预防措施
```

## 数据模型

### 核心实体

```
Department (部门)
  ├── 需求列表 → JobRequisition
  └── 组织架构 → Team

JobRequisition (招聘需求)
  ├── → JD (职位描述)
  ├── → Budget (预算)
  └── → Timeline (时间线)

JD (职位描述)
  ├── 基本信息: 岗位名称、部门、汇报关系
  ├── 职责描述: 核心职责 5-8 条
  ├── 任职要求: 硬性条件 + 软性素质
  ├── 薪酬范围: 带宽 + 福利
  └── 审查记录: PM/技术/HRD 三角色审查结果

Candidate (候选人)
  ├── 简历信息
  ├── 匹配度评分
  ├── 面试记录列表
  └── 状态: 初筛→面试→评估→offer→入职

Interview (面试)
  ├── 问题列表 (岗位定制)
  ├── 评分记录
  ├── 面试官反馈
  └── 综合评估

Employee (员工)
  ├── 入职信息
  ├── 培训记录
  ├── 绩效记录
  └── 发展路径
```

## 实现优先级

### Phase 1: 选 — JD 生成（当前）
- [ ] 需求访谈 Agent（引导部门明确需求）
- [ ] JD 生成（三角色自批评）
- [ ] 行业基准数据（L1 内置 + L2 搜索）
- [ ] JD 质量评估

### Phase 2: 选 — 面试问题
- [ ] 岗位能力模型
- [ ] 问题库（技术/行为/情景/案例）
- [ ] 候选人简历解析
- [ ] 定制化问题生成

### Phase 3: 选 — 简历匹配
- [ ] 简历结构化解析
- [ ] 硬性条件匹配（学历/经验/技能）
- [ ] 软性素质匹配（文化/风格/潜力）
- [ ] 匹配度报告

### Phase 4: 育用留
- [ ] 入职培训计划生成
- [ ] 绩效目标设定
- [ ] 离职风险预警
```
